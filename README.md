# CITY TANKS (WOTANKS-MINI)

Локальная браузерная игра: **3D-ангар и танковый бой от третьего лица**. Откройте `index.html` — регистрация, интернет, сборка и игровой сервер не нужны. Папки `models/`, `vendor/`, `js/` и `css/` должны оставаться рядом с ним. Можно также запустить `python3 -m http.server 8000 --bind 0.0.0.0` из этой папки.

### Зимний сезон · «Северное депо»

Новогодний ангар — единая WebGL-сцена: ремонтный бокс с открытыми воротами, зимний двор, украшенная ёлка, снеговик и танк видны с разных сторон. Снег падает в объёме; над горами и лесом видно северное сияние. При уменьшении движения снег и сияние замирают. Без WebGL 2 остаётся только подписанная миниатюра танка, а не имитация ангара. Исходная сцена `js/depot-room.js` не удалена: сезон выбирается через `data-hangar` в `index.html`.

- **Адвент — 1–31 декабря 2026 включительно, по UTC.** За визит в ангар автоматически начисляются 50 G, 10 000 ₽ и 1 000 XP, каждый седьмой визит вместо этого — 500 G, 50 000 ₽ и 2 заряда. На **15-й разный день** добавляется финский **БТ-42**, на **31-й — TL-7 Олень**. Пропущенный день нельзя забрать задним числом, серия не сгорает. Старый календарь не засчитывается как визиты.
- **Коллекционный контейнер** стоит **150 игрового золота за штуку**. Каждое открытие независимо: **5% на танк суммарно**, **47,5% на 10 000–30 000 серебра**, **47,5% на 25–100 золота**. При выпадении танка шансы равны для всех недостающих машин: **M4A3E2 Sherman Jumbo, T71 DA, Jagdpanther II, Т-62А или TL-7**. После получения всех пяти выпадают только серебро и золото с шансами 50/50. Поддерживаются покупки в инвентарь и массовое открытие.
- **Премиум-магазин** — отдельная витрина. Каждые сутки в **00:00 UTC** обновляется тройка из ИС-6 (7 000 G), Löwe (8 000 G), американского T34 (7 600 G), STA-2 (6 100 G), Strv S1 (6 500 G). Это игровая валюта. Перезагрузка не меняет предложения; уже купленные танки нельзя купить второй раз.
- Все 12 новых машин можно выбрать для боя после получения. У T71 DA барабан 6 × 150 (20 с), у двух TL-7 — 4 × 360 (32 с). У «Оленя» своя модель с рогами, белыми пятнами и красным носом; обычная версия его не открывает. Япония и Финляндия доступны при выборе противника в тренировке, а не как пустые ветки развития.

### Гость и аккаунт Wot-mini

**Гость** запускается без регистрации и сетевых запросов. Для отдельного облачного ангара нажмите **«Гость» → «Создать аккаунт»**: позывной (3–24 латинские буквы, цифры или `_`) и пароль от 8 символов. Почта и почтовая рассылка не требуются. Сохраните пароль: восстановление по почте для позывных не предусмотрено. Существующий подтверждённый email-аккаунт Wot-mini может войти своей почтой и паролем. На другом устройстве нажмите «Войти». **Гостевой и облачный прогресс не смешиваются**: «Выйти в гостевой ангар» возвращает прежнее локальное сохранение.

Сессия аккаунта хранится в текущей вкладке; пароль в сохранение не попадает. Облачные записи защищены RLS по `auth.uid()`. Пока открыта сессия, при потере связи изменения остаются отдельным черновиком этого игрока и отправляются при восстановлении связи. Конфликт версий не затирает другой ангар: панель профиля позволяет скачать копию и загрузить облачную версию. Для входа нужна сеть. День аккаунта определяется по часам Supabase, день автономного гостя — по UTC устройства. Это локальная игра с синхронизацией, а не серверная соревновательная экономика.

В исходном репозитории: схема/политики — `db/`, ограниченная регистрация игровых позывных — Edge Function `supabase/functions/city-tanks-register/`. Она создаёт **только** внутренние идентификаторы позывных, с часовым лимитом попыток; подтверждение настоящей почты в проекте не отключается. В браузерной сборке только publishable key и локальный `@supabase/auth-js` 2.79.0. Никаких привилегированных ключей для запуска игры не нужно.

### Дерево развития: одиннадцать веток, четыре нации, 92 исследуемые машины

- **СССР — путь к ИС-7:** МС-1 → Т-26 → Т-46 → Т-28 → КВ-1 → КВ-1С → ИС → ИС-3 → Объект 257 → ИС-7.
- **СССР — путь к ИС-4:** до КВ-1 включительно машины общие с веткой ИС-7. Дальше: Т-150 → КВ-3 → КВ-4 → СТ-I → ИС-4. Каждая из этих пяти машин стреляет одиночными снарядами.
- **СССР — путь к Объекту 140:** МС-1 → БТ-2 → БТ-7 → А-20 → Т-34 → Т-34-85 → Т-43 → Т-44 → Т-54 → Объект 140.
- **СССР — путь к Т-100 ЛТ:** до А-20 включительно — те же машины, что на пути к Объекту 140. От А-20: Т-50 → МТ-25 → ЛТГ → ЛТТБ → Т-54 обл. → Т-100 ЛТ. Т-54 и Т-54 обл. — разные машины.
- **Германия — лёгкие танки:** Leichttraktor → Pz.Kpfw. II → Pz.Kpfw. I Ausf. C → Pz. II «Luchs» → VK 16.02 Leopard → VK 28.01 → Spähpanzer SP I.C. → HWK 12 → Spähpanzer Ru 251 → Rhm. Panzerwagen.
- **Германия — ПТ-САУ:** Leichttraktor → Panzerjäger I → Marder II → Marder 38T → Pz.Sfl. IVc → Nashorn → Sturer Emil → Rhm.-Borsig Waffenträger → Waffenträger auf Pz. IV → Waffenträger auf E 100.
- **Германия — путь к Maus:** Leichttraktor → Pz.Kpfw. 35 (t) → Pz.Kpfw. 38 (t) → Pz.Kpfw. IV Ausf. D → Pz.Kpfw. IV Ausf. H → VK 30.01 (P) → Tiger (P) → VK 100.01 (P) → Mäuschen → Maus.
- **Германия — путь к E 100:** общий путь до Pz.Kpfw. IV Ausf. H включительно, затем VK 36.01 (H) → Tiger I → Tiger II → E 75 → E 100. Обе ветки используют один узел V уровня; повторная покупка не нужна. У тяжёлого E 100 один выстрел на 680 урона, а Waffenträger auf E 100 из ветки ПТ — отдельная машина с барабаном.
- **США — путь к M48 Patton:** T1 Cunningham → T2 Medium Tank → M2 Medium Tank → M3 Lee → M4 Sherman → M4A3E8 Sherman → T20 → M26 Pershing → M46 Patton → M48 Patton. Все десять машин используют одиночный выстрел с уроном и перезарядкой из таблицы. У M3 Lee основное орудие поворачивается на 15° в каждую сторону от корпуса.
- **Швеция — путь к Kranvagn:** Strv fm/21 → Strv m/38 → Strv m/40L → Lago → Strv m/42 → Strv 74 → Leo → Emil I → Emil II → Kranvagn.
- **Швеция — путь к Strv 103B:** Strv fm/21 → Pvlvv fm/42 → Ikv 72 → Sav m/43 → Ikv 103 → Ikv 65 Alt II → Ikv 90 Typ B → UDES 03 → Strv 103-0 → Strv 103B.

Чтобы начать шведское дерево: **«Дерево развития» → «Швеция» → Strv fm/21**. От одной бесплатной машины I уровня открываются два независимых узла II уровня. У СССР есть ещё одна развилка на V уровне: с одного КВ-1 исследуется КВ-1С или Т-150. Если КВ-1 уже в ангаре, повторно проходить I–V не нужно. Просмотр ТТХ закрытого узла не тратит опыт и не меняет танк для боя. Нажатие на доступный узел исследует и выбирает машину, на уже исследованный — только выбирает. Для открытия нужен предыдущий узел **своей линии**, а не просто танк того же уровня; на телефоне схему можно листать пальцем или стрелками. Цены I–X одинаковы для всех одиннадцати веток: 0, 150, 350, 1 500, 4 000, 8 000, 25 000, 60 000, 120 000 и 195 000 XP. Стартовые машины нельзя продать.

В новом профиле есть МС-1 и **500 XP**. На вкладке «Мой танк» вращается только открытая и выбранная машина. В дереве, карусели и списке команд у каждого танка своя иконка, отрисованная с его модели. Чтобы выехать, нажмите «В БОЙ 15×15», «7×7», «10×10» или «Тренировка» и выберите управление. Команды получают одинаковый набор машин четырёх наций в пределах одного уровня от игрока. В тренировке можно выбрать нацию и любую из 104 машин противника.

**Шведские машины.** Emil I стреляет тремя снарядами по 320, Emil II и Kranvagn — тремя по 400. Полная перезарядка после третьего выстрела: 22, 25 и 22 с соответственно. Верхняя часть качающейся башни движется со стволом. На UDES 03, Strv 103-0 и Strv 103B горизонтальная наводка — поворотом корпуса. У финальных Strv подъём и склонение идут через подвеску; у UDES подвеска опускает нос, а вверх поднимается само орудие.

**Немецкие ПТ-САУ.** Для II–VII уровней прочерк в колонке брони означает, что отдельной башни нет: попадание в рубку проверяется по броне корпуса. Орудие поворачивается в пределах сектора своей модели; чтобы навестись дальше, доверните корпус. У Rhm.-Borsig, WT auf Pz. IV и WT auf E 100 установки вращаются по кругу. У X уровня базовый барабан **4 выстрела по 520** (всего 2 080 при четырёх пробитиях), затем полная перезарядка **40 с**. Это обычная исследуемая машина, не событийный босс.

**Немецкие кассеты.** Pz.Kpfw. II стреляет 5 раз по 15 (всего 75; полная перезарядка 4,5 с), Pz.Kpfw. I Ausf. C — 8 по 12 (96; 5 с), Luchs — 6 по 30 (180; 7,5 с), Leopard — 8 по 30 (240; 9 с). Держите кнопку огня для очереди. Игровой интервал внутри кассеты — 0,12 с; указанное в таблице КД начинается после последнего выстрела. У Leopard выбран кассетный вариант с пробитием 105 мм. У VK 28.01 — одиночный выстрел на 115, КД 3,6 с и пробитие 135 мм. Альтернативных орудий у этих машин нет.

**Т-46 — пулемёт, 60 базового урона за весь барабан, а не за патрон.** Для игры барабан разделён на 6 патронов по 10: удержание огня выпускает очередь, отпускание останавливает её, остаток виден в HUD. Пустой барабан перезаряжается за 2,8 с (базовая комплектация), пробитие — 65 мм. Промахи и непробития расходуют патрон без урона. В отличие от обычных пушек у пулемёта один тип боеприпаса. Улучшения и критические повреждения учитываются отдельно от базовых ТТХ. Для скорости ИС-7 из диапазона 55–59 км/ч в игре взяты 55 на обычном грунте и 59 на асфальте.

### Карты и боты

В ангаре выберите **«Карта» → «План сектора»**: на схеме видны препятствия, вода и старты команд. Все шесть полей доступны для **15×15, 10×10, 7×7 и тренировки**. В 15×15 вы и 14 союзных ботов играете против 15 ботов. Размеры ниже — границы проезда, а не размеры фоновой декорации.

| Сектор | Размер | Местность |
| --- | --- | --- |
| Литейный квартал | 700 × 700 м | Семь поперечных улиц, кварталы цехов и широкий проспект |
| Зелёная долина | 1000 × 1000 м | Внешние поля и фермы, четыре пруда и дальние просёлки |
| Песчаный рубеж | 1000 × 1000 м | Каменные ворота, дюны и боковые пути вдоль гряд |
| Грузовой порт | 800 × 800 м | Контейнерные ряды, причалы и склады; старт с севера и юга |
| Медный карьер | 1000 × 1000 м | Два гравийных кольца, каменные уступы и площадки добычи |
| Ледовая переправа | 1000 × 1000 м | Заснеженные берега и пять ледовых переходов |

Высоты находятся **на игровых маршрутах**, а не только за границей поля. В квартале дороги поднимаются между цехами, в порту съезжают к причалам, в долине огибают фермерские холмы. Пустыню пересекают песчаные гряды; в карьере уклоны ведут в центральную чашу, на зимней карте — с сопок к ледовым переходам. Площадки под строениями выровнены на своей высоте, линия стрельбы на тренировочном старте остаётся ровной.

**Как увидеть разведку.** На старте 15×15 пять машин с каждой стороны получают разные участки для разведки. Светлое кольцо на мини-карте отмечает своего разведчика. Тёмные клетки светлеют, когда вы или союзник заезжаете в них; счётчик «Разведано» показывает ход обследования. Это история посещений, а не постоянная видимость врага. У второй команды своя карта; при новом выезде обе начинают с нуля.

Без контакта боты выбирают ещё не проверенные клетки, а когда таких не осталось — возвращаются туда, где давно никого из своих не было. При повторном осмотре проверяют другую часть клетки. Они объезжают воду и препятствия, меняют застрявший маршрут и могут воспользоваться проездом после разрушения здания. Обнаруженную машину видят на мини-карте союзники. При потере контакта ближайшие боты могут проверить последнее сообщение; оно устаревает за пять игровых секунд и не обновляется, пока враг снова не обнаружен. Для выстрела нужна открытая линия огня. В тренировке противник по-прежнему стоит напротив игрока на открытом участке.

В воду можно заехать с мелкого берега. Отсчёт затопления начинается, когда вода накрывает большую часть корпуса. Запаса хватает на десять секунд полного погружения; на мелководье и на суше он постепенно восстанавливается.

### Управление

Первый щелчок на поле или кнопка **«Взять управление»** захватывает мышь, но не стреляет. Крест прицела остаётся на экране, а малое золотое кольцо показывает, куда сейчас направлен ствол. После резкого поворота дождитесь, пока кольцо догонит крест: снаряд летит из ствола, а не из камеры. У машин с ограниченным сектором, например M3 Lee, за пределами сектора нужно довернуть корпус. Низкая преграда может остановить снаряд, даже если цель видна поверх неё.

| Действие | ПК | Телефон / планшет |
| --- | --- | --- |
| Ход и поворот корпуса | **WASD** или **стрелки**; **пробел** — тормоз | Начните движение пальцем в левой нижней части поля. Джойстик появится под пальцем |
| Обзор | Двигайте мышь. Башня поворачивается за прицелом. Удерживайте **ПКМ**, чтобы осмотреться, не вращая башню относительно корпуса | Ведите другим пальцем по полю или по зажатой кнопке огня |
| Огонь | **ЛКМ**, можно удерживать | **Огонь**, можно удерживать одновременно с джойстиком |
| Оптика | **Shift** — вход/выход. Колесо приближает или отдаляет камеру (6–26 м). Ещё шаг внутрь от 6 м — оптика; в ней колесо меняет **×2 / ×4 / ×8**, шаг наружу от ×2 — выход | **Прицел** — вход/выход. Кнопка кратности перебирает **×2 / ×4 / ×8** |
| Автоприцел | **E** — захватить видимого противника около креста; ещё раз — снять | **Авто** |
| Состав и пауза | Удерживайте **Tab** для состава. **Esc** или потеря захвата — пауза; **«Продолжить»** снова захватывает мышь | Нажмите на счёт для состава, **Меню** — пауза |

Обзор не поворачивает корпус, а камера сокращает дистанцию у стен. Чувствительность меняется в настройках ангара (0,3–2,5) и снижается при увеличении оптики. Автоприцел ведёт башню, а не камеру; при потере видимости или уничтожении цели захват снимается. Если браузер запрещает захват курсора, работает относительный обзор в пределах поля: удерживайте **Alt**, чтобы переставить мышь без поворота камеры.

**Вождение.** Физика работает с фиксированным шагом 1/60 с. Чем выше скорость, тем меньше запас тяги; на подъёме и в повороте танк теряет ход. Отпустите газ для наката, нажмите пробел для торможения. Команда обратного хода сначала гасит скорость, затем включает заднюю передачу. При движении назад направление поворота корпуса меняется. На льду длиннее тормозной путь.

Корпус опирается на рельеф в четырёх точках: крен и наклон видны и по танку, и по стволу. Холм между машинами закрывает обзор и останавливает снаряд. Под полосой прочности показаны скорость со знаком, покрытие и уклон. При столкновении учитываются габариты и игровая масса: лёгкую машину сдвигает сильнее, а быстрый удар о противника может снять прочность у обоих. Отдельно стоящие деревья на опушках можно повалить. Сбитая гусеница останавливает танк до ремонта (автоматически через семь секунд или сразу ремкомплектом). Для ботов действуют те же правила. Масса, мощность, поворот и задняя передача настроены под игровые классы; предельные скорости машин и улучшения берутся из прежнего каталога.

На ПК **1–3** выбирают снаряд (у кассеты/барабана тип один). **5/Q** — ремонт, **6/F** — огнетушитель, **7** — дым, **8** — местная артподдержка в точку прицела. **4** — аптечка (+15% прочности), **R** — адреналин, **9** — паёк, **0** — топливо. Сигналы **Z/X/C/V/B** выводят реплику на поле; на телефоне они собраны под **«Связь»**. Это бой с ботами, без сетевого чата. Гибель игрока, как и раньше, завершает выезд: пробел служит тормозом, а не переключателем наблюдения. На мини-карте видны свои и обнаруженные противники. **«В ангар»** в меню даёт выйти без итоговой награды; после завершённого боя откроется экран результатов.

Камера, корпуса, башни, стволы, снаряды и укрытия находятся в одной WebGL-сцене. Луч полёта различает корпус и повёрнутую башню. Пробитие снаряда сравнивается с игровой бронёй поражённой части с учётом стороны попадания. Мини-карта и интерфейс остаются плоскими. Для боя необходим **WebGL 2**: если он недоступен, появится объяснение и кнопка возврата, а не подмена на 2D-бой. Ангар при этом показывает снимок реальной модели.

### Модели

- `models/catalog.js` хранит таблицы всех одиннадцати веток: уровни, ТТХ, исследование и ссылки на файлы. Каталог `DB` объединяет их с 12 особыми машинами, которые нельзя исследовать за XP. `alpha` — урон **полной** базовой зарядки, `shotDamage()` делит его на число патронов. Скорость задаётся в км/ч, перезарядка — в мс.
- `models/*.mesh.js` — только данные 104 предоставленных моделей: координаты, индексы, цвета и центры поворота. Отдельных страниц-карточек нет. На диск можно переносить игру целиком: ангар и бой подгружают ту же геометрию по мере необходимости, без сети и без `fetch()` с `file://`. Игровые экземпляры разделяют сетку, но не прицел и боезапас.
- В **зимнем депо** (`js/winter-bay.js`) можно облететь выбранную машину вместе с её окружением, изменить масштаб или выбрать один из четырёх ракурсов. При отключённом WebGL показывается статичное изображение выбранного танка.
- Импорт из исходных файлов этого формата: `python3 tools/import_models.py /папка/с/моделями`. Скрипт извлекает данные, не выполняя код из HTML; исправленный `*-game-fixed.html` имеет приоритет. Добавьте строку в `models/catalog.js`. Иконки на прозрачном фоне создаёт `node tools/render_icons.cjs` (нужны зависимости из `tests` и Chromium). Источник геометрии указан в каждом файле; локальная сборка Three.js — в `vendor/` (MIT).
- Офлайн-загрузку `CITY-TANKS.zip` можно пересобрать: `python3 tools/package_game.py`.

### Сохранение

Гостевой профиль на браузер/адрес, ключ `ct_progress_v1`. При обновлении ZIP закройте игру и распакуйте новую версию в прежнюю папку: при смене пути `file://` браузер может использовать другое хранилище. При обновлении сохраняются исследованные машины с моделями **включая ранее открытые IX и X**, выбор для боя, валюта, модули, улучшения, настройки, календарь, бустеры, инвентарь и статистика. Распознаются прежние ключи `PZ2`, `SP1C`, `T1CUNN`, `OB140`, `RHMB`, `STRV21` и `ST1`, а также старые обозначения новых машин (например, `TIGER1` и `T54O`). Ивентовый WT E 220 и обычный WT auf E 100 — разные машины. Старый T2 Light не считается T2 Medium; это не открывает некупленные машины. Если выбранная машина не поддерживается, выбирается доступная; пустому гаражу выдаётся МС-1. Старые тематические контейнеры переносятся в ресурсные ящики. Незавершённый бой и данные удалённых сервисов не записываются.

Обычные награды за бой и аптечка остались. Сейфы, колесо, лига, босс-рейд, почта, кланы, боевые и ежедневные задания, старые бонусы коллекции, боевой пропуск, камуфляжи, экипажи, чертежи, новости и достижения удалены вместе с их бонусами.

Если основного сохранения нет, можно перенести прогресс одного прежнего локального аккаунта; при нескольких аккаунтах игра не выбирает владельца за вас. Старые записи не удаляются, пароль не переносится. Если браузер блокирует хранилище, играть можно без записи; нечитаемое сохранение не перезаписывается.

### Проверка

```sh
cd tests && npm ci
npx playwright-core install chromium
npm test
```

Для тестов нужен Node.js 22.13+ (самой игре Node.js не нужен). Можно задать `CHROMIUM_PATH` для уже установленного Chromium. Тесты запускают игру с диска без сети, проверяют миграцию и награды, отсутствие WebGL и настоящий 3D-бой через программный WebGL: все 104 комплекта геометрии и миниатюр, параллакс ёлки, снеговика и ворот при свайпе в 3D-депо, паузу снега, цену и границы выпадения наград из коллекционного ящика, связи и цены узлов, захват и освобождение мыши, независимый обзор, ограниченную скорость башни, оптику и прицельный луч, попадания, урон полной кассеты Leopard и барабанов Т-46, WT auf E 100 и Kranvagn, результат, повторный выезд и мультитач. Проверяется также совпадение ствола и выстрела при наклоне шведской подвески. Отдельные тесты проверяют ТТХ всех веток, темп стрельбы, броню, предел поворота M3 Lee, разгон, торможение, реверс, скольжение и столкновения.

Проверки карт охватывают связность маршрутов, старты обеих команд, проезд в обход препятствия, обновление навигации после разрушения, разделение разведывательных задач, посещение новых клеток без контакта, старение донесений и затопление. Браузерный тест разворачивает 7×7, 10×10 и 15×15 на каждом из шести полей и проверяет движение ботов, обнаружение, выстрелы и списание HP. Для проверки распакованной версии можно задать `CITY_TANKS_INDEX=/путь/к/index.html`.
