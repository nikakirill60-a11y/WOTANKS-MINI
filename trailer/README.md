## Как снято

Игровая база — выпуск `8d78ecd1f422c9a5615223161f09102048e2633d`. Съёмки ведутся с диска в изолированном гостевом профиле Chromium с WebGL 2 без сети. Игроку не меняются сохранение, экономика или бой. В кинематографических планах камера поставлена для съёмки; в кадрах первого боя, дерева, промокода и арт-прицела виден интерфейс игры. Студийные портреты используют те же локальные трёхмерные модели.

- `editions/shoot.cjs`: МС-1, Leichttraktor, КВ-1, Tiger (P), Maus, ИС-7; получение САУ через настоящий `ARTA`, 4 → 3 при выезде, съёмка реального вида сверху со сведением и выстрелом. Составы примера 7×7 выдаёт `makeRosters`. Обе линейки I–X берутся из каталога игры.
- `editions/inserts.cjs`: первый бой на МС-1 и исследование Т-26 за 150 из 500 стартовых XP. `editions/studio.cjs`: съёмка вращения игровых моделей для карточек.
- `capture.cjs`: первая съёмочная группа; здесь берутся движение Leopard 1, выход союзников 15×15 и проверенный одновременный залп СТ-II на 440 + 440.
- `editions/cuts.py`: монтажный лист, таймкоды диктора, встроенные субтитры WebVTT. `editions/voice/`: записанные для этих изданий синтезированные русские реплики. `editions/mix.py`: синтез музыки и эффектов, приглушение под речь. Для пересборки не нужны сетевой сервис озвучки или библиотека звуков.
- `editions/picture.py`, `editions/build.py`: графика, монтаж и кодирование. `theatre.py` + `player.html.in`: единый автономный HTML, без CDN, трекеров или подгрузки видео. Шрифт Oswald (© 2016 The Oswald Project Authors, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/oswald)) — SIL OFL 1.1, исходная лицензия в `fonts/OFL.txt`, копия в HTML.

## Пересборка (только для разработки)

Если нужны только MP4 из уже готовых ZIP, после установки `trailer/requirements.txt` выполните `python trailer/editions/export_mp4.py`. Оба файла появятся в `trailer/dist/`; съёмка, синтез озвучки и повторное сжатие не нужны. Можно выбрать одно издание (`--edition full` или `--edition update`) и каталог (`--output-dir`).

Для полной пересборки: из корня репозитория, Python 3.11+, Node.js и Chromium с WebGL 2/H.264. Сырые кадры, WAV и промежуточные `film.mp4` держите **вне Git**. Две команды ниже относятся к прежним изданиям и не перезаписывают MP4 версии 1.4.

```sh
WORK="$(mktemp -d)"
UNIT1="$WORK/first-unit"
python3 -m venv "$WORK/env" && . "$WORK/env/bin/activate"
python -m pip install -r trailer/requirements.txt
npm ci --prefix tests
# Задайте CHROMIUM_PATH или установите движок: tests/node_modules/.bin/playwright-core install chromium
node trailer/capture.cjs "$UNIT1" drive salvo team
node trailer/editions/shoot.cjs "$WORK"
node trailer/editions/inserts.cjs "$WORK"
node trailer/editions/studio.cjs "$WORK"
python trailer/editions/build.py full "$WORK" "$UNIT1"
python trailer/editions/build.py update "$WORK" "$UNIT1"
node trailer/check.cjs
```

Для чернового листа кадров: снимите также `node trailer/capture.cjs "$UNIT1" --proof drive salvo team` и `node trailer/editions/shoot.cjs "$WORK" --proof`, затем передайте `--stills` в `build.py`. Опция `--package-only` повторно собирает плеер с готовыми `film.mp4` и `poster.webp` данного издания без повторного кодирования. Артефакты можно положить в другую существующую папку через `--output-dir`.

`check.cjs` проверяет CRC и единственный файл в каждом ZIP, затем проигрывает извлечённый HTML с `file://` в отключённых от сети настольной и сенсорной сессиях. Проверяются длительность, размер, русские субтитры, главы, перемотка, звук, конец и повтор. Для полного трейлера проверяются точный адрес Telegram и доступность кликабельной области финального кадра. Можно передать конкретный ZIP; `TRAILER_STILLS` задаёт каталог проверочных снимков.

Первоначальный 40-секундный зимний тизер **«Двойной залп»** сохранён [в прежнем выпуске](https://github.com/nikakirill60-a11y/WOTANKS-MINI/raw/7ca432ebe074a0895da3e24c755b90c1d5dd7367/CITY-TANKS-TRAILER.zip). Его отдельный монтаж `assemble.py` по умолчанию создаёт `CITY-TANKS-WINTER-TEASER.zip` в рабочем каталоге материалов, а не перезаписывает полный трейлер. `CITY-TANKS.zip` не меняется.
