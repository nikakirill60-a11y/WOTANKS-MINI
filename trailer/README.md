# Двойной залп · CITY TANKS

**Посмотреть:** распакуйте [`CITY-TANKS-TRAILER.zip`](../CITY-TANKS-TRAILER.zip) в отдельную папку и откройте `index.html` в браузере. В архиве ровно один файл. В него встроены фильм со звуком, постер, шрифт и плеер. Не нужны установка, игровой архив, WebGL, сервер или сеть. Не распаковывайте поверх папки игры: её стартовый файл тоже называется `index.html`.

**40 секунд · 1280 × 720 · 24 кадра/с · H.264 / AAC, стерео.** Воспроизведение по нажатию, без автозвука. Можно выбрать сцену, перемотать, выключить звук, развернуть экран и повторить показ. `K` — пауза/старт, `M` — звук, `F` — полный экран, стрелки ←/→ вне элементов управления — переход на пять секунд. Под плеером есть текстовая версия. Без JavaScript остаются стандартные кнопки видео.

## Как это снято

Исходный игровой выпуск — `8d78ecd1f422c9a5615223161f09102048e2633d`. `capture.cjs` открывает игру с диска в изолированных гостевых сессиях Chromium без сети. Камера и часы заданы сценарием. Ангар, движение, команды, снаряды и попадания отрисовывает сама игра. Для замедленного плана СТ-II режиссёр вызывает игровое действие один раз и проверяет два разных снаряда и изменение счёта. Пользовательские сохранения не используются. Постер — `assets/depot-entry.webp`; миниатюры — `models/obj-277.webp` и `models/kpz-67.webp`.

`assemble.py` монтирует кадры, накладывает титры, добавляет музыку, кодирует фильм и встраивает данные в `player.html.in`. Инструментальная музыка и эффекты синтезируются `score.py` специально для этого фильма. Шрифт Oswald (© 2016 The Oswald Project Authors, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/oswald)) распространяется по SIL OFL 1.1; оригинал лицензии — `fonts/OFL.txt`, копия включена в HTML. Сборка не меняет `CITY-TANKS.zip`.

## Пересборка (только для разработки)

Нужны Python 3.11+, Node.js, Chromium с WebGL 2 и H.264 и зависимости ниже. На Linux можно использовать программный SwiftShader. Промежуточные кадры, WAV и MP4 сохраняйте **вне** репозитория.

```sh
# Из корня репозитория:
WORK="$(mktemp -d)"
python3 -m venv "$WORK/env"
. "$WORK/env/bin/activate"
python -m pip install -r trailer/requirements.txt
npm ci --prefix tests
# Укажите установленный Chromium или установите движок Playwright:
# export CHROMIUM_PATH=/путь/к/chromium
# tests/node_modules/.bin/playwright-core install chromium
node trailer/capture.cjs "$WORK"
python trailer/assemble.py "$WORK"
node trailer/check.cjs CITY-TANKS-TRAILER.zip
```

Пробный монтаж без полного рендера: `node trailer/capture.cjs "$WORK" --proof`, затем `python trailer/assemble.py "$WORK" --stills`. Можно переснять только одну сцену, например `node trailer/capture.cjs "$WORK" salvo`. После изменений плеера `python trailer/assemble.py "$WORK" --package-only` использует уже закодированный `film.mp4`. Архив состоит только из `index.html`, не из исходников и дублей ролика.

`check.cjs` проверяет CRC и состав итогового ZIP, извлекает его во временную папку, затем проигрывает с `file://` при отключённой сети с обычным и сенсорным управлением. Проверяются длительность, размер видео, пауза, звук, перемотка, главы, полный экран, конец и повтор. Для скриншотов можно задать каталог `TRAILER_STILLS`.
