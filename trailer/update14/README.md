# Зимний выезд · CITY TANKS 1.4

**[Смотреть / скачать готовый MP4 (4:05)](../../CITY-TANKS-1.4-TRAILER.mp4)**. Игра и сеть для просмотра не нужны. Съёмочная версия игры: `1ce2988`.

### Озвучка

Фильм открывается полным [выбранным вступлением](../voices/ru-narrator/reference.mp3) с вопросом «Куда поедем сначала?». Остальные [11 чистых записей](voice/) — тот же русский диктор **`voice-02`**, включая рассказ о каждой карте и финальное приглашение в Telegram. Это не нарезка из выпуска 1.3. Исходники не ускоряются, не меняют высоту тона и не требуют повторного синтеза.

- В `narration.py` — путь, контрольная сумма и время старта каждого дубля, а также 82 фразы с таймкодами относительно исходника. В субтитрах числа и марки машин даны в обычном написании.
- `edit.py` привязывает планы и главы к рассказу. В таблицах по ходу речи подсвечиваются нужный параметр, игрушка или машина; крышка ларца открывается на словах «Подними крышку».
- `score.py` сводит музыку, эффекты и чистые дубли. Музыка приглушается во время речи. Обе русские текстовые дорожки — реплики и описание — можно отключить.

### Канал в финале

С **3:57** на самом изображении, а не в интерфейсе плеера, видны **[@blitz_legacy](https://t.me/blitz_legacy)**, полный адрес и QR-код. Звучит: «Заглядывай в наш телеграм-канал „Блиц Легаси“. Ссылка на экране. Увидимся в игре!» Адрес взят из `FULL['telegram']` предыдущего фильма «От I до X». В MP4 он также записан в метаданных и описательной дорожке. Открывать канал во время просмотра необязательно.

### Съёмка и проверка

- `shoot.cjs` снимает игру с `file://` без сети. Полигонный дубль проверяет переключение в обе стороны, заблокированный выстрел во время перехода и снаряд на 380. Панорамы используют `BattleMaps`, игровой рельеф, модели зданий и `MapChart`.
- Совместный выезд поставлен в `PlatoonMatch` с тремя локально управляемыми местами и одиннадцатью штатными ботами, без регистрации аккаунтов. Для ёлки сделаны четыре выбора в игре; на подложке открытого ларца показан ровно один 3D-пряник.
- `editions/studio.cjs` снимает вращающиеся модели; `ledger.cjs` читает каталог, предыдущие узлы веток и правила украшений. `picture14.py` проверяет полноту отснятых дублей перед монтажом.
- `check.py` полностью декодирует H.264/AAC, проверяет главы, содержание **и время** обеих дорожек текста, а также каждую сцену. Сопоставляет речь в финальном миксе с чистыми записями **для каждой фразы**, включая вступление и название канала. Считывает QR из кадров сжатого фильма при ширине 390 пикселей и сравнивает с адресом из предыдущего трейлера.

### Пересобрать из корня репозитория

Нужны Python 3.11+, Node.js, `npm ci --prefix tests` и Chromium с WebGL 2 (`CHROMIUM_PATH` при необходимости). Сырые кадры и промежуточные рендеры остаются вне Git. Для сборки достаточно `trailer/requirements.txt`; дополнительная зависимость проверки нужна только для считывания QR.

```sh
python -m pip install -r trailer/update14/requirements-check.txt
WORK="$(mktemp -d)"
node trailer/editions/studio.cjs "$WORK" AMX-M4-54 B-C-25-T AMX-50-B FOCH-155 T110E3 T110E4 ARES-90 STURMTIGER KPZ-67 PZ-II-J T67
node trailer/update14/shoot.cjs "$WORK"
python trailer/update14/build.py "$WORK" --boards  # необязательно: лист кадров в WORK/review
python trailer/update14/build.py "$WORK"
python trailer/update14/check.py CITY-TANKS-1.4-TRAILER.mp4
node trailer/update14/play.cjs CITY-TANKS-1.4-TRAILER.mp4  # запуск и перемотка без сети на ПК и телефоне
```

Отдельный план можно переснять его именем после `$WORK`. `--plans` обновляет только схемы секторов. `--output` у `build.py` меняет путь итогового MP4. `telegram.png` — статический QR адреса канала (Segno 1.6.6, `make_qr(url, error='q')`, `scale=8, border=4`); при сборке обращения к внешнему генератору нет. `CITY-TANKS.zip` не меняется.
