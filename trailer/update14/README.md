# Зимний выезд · CITY TANKS 1.4

**Готовый файл:** [`CITY-TANKS-1.4-TRAILER.mp4`](../../CITY-TANKS-1.4-TRAILER.mp4). Игра, прежние фильмы и сетевые сервисы для просмотра не нужны. Съёмочная версия игры: `1ce2988`.

### Голос и звук

В `edit.py:VOICE` — на каком таймкоде звучит каждый **оригинальный фрагмент выпуска 1.3**, имя `editions/voice/u*.mp3`, вход, выход и точный русский субтитр. Отрезки берутся до сведения с музыкой; название 1.3, прежняя акция ARTA и награды прошлого выпуска в новый фильм не переходят. Никто другой не читает реплики. Для нового материала используются игровые планы и русские титры, а не имитация голоса. Полные описания есть также на второй текстовой дорожке MP4. `score.py` пишет новую инструментальную музыку и эффекты, приглушая их во время речи. `build.py` проверяет SHA-256 исходных дублей.

### Кадры и проверка

- `shoot.cjs` снимает текущую игру с `file://` без сети. В полигонном дубле проверяет переключение в обе стороны, заблокированный выстрел во время перехода и реальный снаряд на 380. Для панорам использует `BattleMaps`, игровой рельеф, модели зданий и `MapChart`, а не иллюстрации карт.
- Совместный план — постановочный игровой выезд в `PlatoonMatch` с тремя локально управляемыми местами и одиннадцатью штатными ботами. Нет регистрации настоящих аккаунтов и записи в базу. Для ёлки используются четыре настоящих выбора в меню; в дубле ларца на подложке оставлен ровно один 3D-пряник.
- `editions/studio.cjs` снимает вращающиеся игровые модели. `ledger.cjs` читает каталог, реальные предыдущие узлы веток и правила украшений. `picture14.py` проверяет полноту отснятых дублей перед монтажом.
- `check.py` полностью декодирует финальный H.264/AAC, проверяет все главы, дорожки текста и изображение каждого плана. Сравнивает форму волны **каждой** реплики, декодированной из готового MP4, с чистым оригиналом 1.3: похожего тембра для этой проверки недостаточно.

### Пересобрать из корня репозитория

Python 3.11+, `trailer/requirements.txt`, Node.js, `npm ci --prefix tests`, Chromium с WebGL 2 (можно указать `CHROMIUM_PATH`). Сырой материал остаётся за пределами Git; новые модели голоса и внешние сервисы не требуются.

```sh
WORK="$(mktemp -d)"
node trailer/editions/studio.cjs "$WORK" AMX-M4-54 B-C-25-T AMX-50-B FOCH-155 T110E3 T110E4 ARES-90 STURMTIGER KPZ-67 PZ-II-J T67
node trailer/update14/shoot.cjs "$WORK"
python trailer/update14/build.py "$WORK" --boards  # необязательно: лист кадров в WORK/review
python trailer/update14/build.py "$WORK"
python trailer/update14/check.py CITY-TANKS-1.4-TRAILER.mp4
node trailer/update14/play.cjs CITY-TANKS-1.4-TRAILER.mp4  # запуск и перемотка без сети на ПК и телефоне
```

Отдельный план можно переснять его именем после `$WORK`. `--plans` обновляет только планы секторов. `--output` у `build.py` меняет путь итогового MP4. `CITY-TANKS.zip` не изменяется.
