## Как пересобрать

Для точной пересборки используйте [исходники релиза 1.5](https://github.com/nikakirill60-a11y/WOTANKS-MINI/tree/7aad640dac877dd4337a6c1989f1c315a7f2ca5d): в ролике показан первоначальный шанс танка из национального ящика (2%). После съёмки правила изменились: теперь у каждой недостающей машины свой шанс по уровню, в том числе по 0,05% на каждую машину X уровня за ящик (см. [актуальную шкалу](../../README.md#национальные-ящики-за-победу-и-110-особых-машин)). Шанс самого ящика за победу в командном бою остался 20%.

Съёмка идёт с `file://`, в отдельных гостевых контекстах без сети. Поставлены только камера, движение и пример исхода рулетки; прогресс игрока и правила игры не меняются. Сырьё хранится вне репозитория. Нужны Node.js, Chromium с WebGL 2, Python 3.11+ и зависимости `trailer/requirements.txt`.

```sh
WORK="$(mktemp -d)"
# В отдельном Python-окружении:
python -m pip install -r trailer/requirements.txt
npm ci --prefix tests
# При необходимости укажите CHROMIUM_PATH.
node trailer/editions/studio.cjs "$WORK" GWE100 OBJ261V4 OBJ261 BC15558 AMX13105 EBR105 PROJETMURAT NAT013 NAT035 NAT014
node trailer/update15/capture.cjs "$WORK"   # ledger, wheel, burgstadt, port, drive
node trailer/update15/foley.cjs "$WORK"     # PCM из игрового SectorFoley
python trailer/update15/build.py "$WORK" --boards  # необязательный лист монтажа
python trailer/update15/build.py "$WORK"
python trailer/update15/check.py CITY-TANKS-1.5-TRAILER.mp4
```

`capture.cjs` сверяет маршруты, шансы и цену с текущей сборкой. Для реального выезда в `slate.json` фиксируются движение и кадр единственного выстрела; в `receipt.json` — реальная выдача за один оплаченный прокрут тестового гостя. `edit.py` содержит монтажный лист и текст диктора; `sound.py` на время выезда полностью убирает музыку. `check.py` декодирует готовый MP4 целиком и проверяет главы, размеры, все фразы субтитров и совпадение каждой фразы в финальном звуке с соответствующей чистой записью `voice-02`.
