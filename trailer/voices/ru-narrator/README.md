# Выбранный голос для русских трейлеров CITY TANKS

Пользователь выбрал этот голос на прослушивании вступления «Зимнего выезда» и попросил его запомнить. Использовать для следующих озвучек, если пользователь не попросит другой. Этот образец открывает [трейлер 1.4](../../../CITY-TANKS-1.4-TRAILER.mp4). Все остальные [реплики, включая приглашение в Telegram](../../update14/voice/), записаны тем же выбранным голосом.

- Голос, зарегистрированный в этой сессии Arena: `voice-02` (прослушивание `02`, язык `ru`).
- [Чистый звуковой образец](reference.mp3) — та же вступительная реплика, записанная выбранным голосом, без музыки. Это новый выбор, а не архивная запись диктора 1.3.
- Реплика: «В ангаре зажглась ёлка, а за воротами ждут четыре новые карты. Куда поедем сначала? Решать тебе. Выбирай танк, зови друзей во взвод — и встречай „Зимний выезд“, обновление один точка четыре для Сити Танкс».

Для [трейлера 1.5](../../update15/README.md) этот же `voice-02` успешно использован напрямую: [вступление 1.5](../../update15/voice/01-depot.mp3) и все девять следующих реплик. Контрольные суммы записей — в [ведомости 1.5](../../update15/voices.json). Предпочтение не менялось: автоматически предложенный другой голос не заменяет выбор игрока.

Идентификатор относится к этой сессии, не является глобальным названием пресета. При следующей озвучке сначала проверить сохранённый `voice-02`, а не начинать новое прослушивание. Если в другой сессии он действительно недоступен, образец остаётся для сверки; сообщить об ограничении, не подменять голос.
