# Выбранный голос для русских трейлеров CITY TANKS

Пользователь выбрал этот голос на прослушивании вступления «Зимнего выезда» и попросил его запомнить. Использовать для следующих озвучек, если пользователь не попросит другой. Уже выпущенный MP4 версии 1.4 не перемонтирован.

- Голос, зарегистрированный в этой сессии Arena: `voice-02` (прослушивание `02`, язык `ru`).
- [Чистый звуковой образец](reference.mp3) — та же вступительная реплика, записанная выбранным голосом, без музыки. Это новый выбор, а не архивная запись диктора 1.3.
- Реплика: «В ангаре зажглась ёлка, а за воротами ждут четыре новые карты. Куда поедем сначала? Решать тебе. Выбирай танк, зови друзей во взвод — и встречай „Зимний выезд“, обновление один точка четыре для Сити Танкс».

Идентификатор относится к текущей сессии, не является глобальным названием пресета. Если в другой сессии исходный голос недоступен, образец остаётся для сверки; не использовать неподтверждённую замену.
